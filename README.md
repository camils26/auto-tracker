# Auto-Track

**Autor:** Ana Camila López Sánchez
**Nombre del sistema:** Auto-Track 

## Descripción

AutoTrack es un sistema de gestión y seguimiento de ventas de vehículos diseñado para facilitar el trabajo de los vendedores y gerentes. Permite registrar y consultar la información de los clientes, dar seguimiento a sus oportunidades de compra y conocer en qué etapa se encuentra cada proceso de venta, desde el primer contacto hasta la negociación y cierre. Además, busca centralizar la información y facilitar el seguimiento de los clientes para evitar la pérdida de oportunidades de venta.
