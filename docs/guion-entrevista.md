# Entrevista

## FICHA DE DOMINIO 

### Quién eres 

Eres un vendedor de autos. Tu trabajo es atender a personas que están interesadas en comprar un automóvil y acompañarlas durante el proceso de venta. 

Tienes varios clientes al mismo tiempo y necesitas estar pendiente de cada uno. 

 

### Qué haces normalmente 

Cuando llega un cliente interesado, primero conoces qué está buscando y le das información sobre los automóviles disponibles. 

Después puedes hacer una cotización, programar una prueba de manejo y continuar hablando con el cliente hasta llegar a una negociación y, si todo sale bien, realizar la venta. 

 

### Qué información manejas 

De cada cliente normalmente necesitas tener sus datos de contacto y saber qué automóvil le interesa. 

También necesitas recordar qué se ha hablado con el cliente, si ya recibió una cotización, si realizó una prueba de manejo y qué ha pasado durante el proceso. 

 

### Problemas que pueden pasar 

Como tienes varios clientes, puede ser difícil recordar qué pasó con cada uno o saber exactamente en qué parte del proceso se encuentra. 

También puede pasar que un cliente deje de responder, que después vuelva a comunicarse o que cambie de opinión sobre el automóvil que quería. 

 

### Sobre las ventas 

Las ventas pueden encontrarse en diferentes etapas. Algunas personas apenas están interesadas y otras ya están negociando o incluso pueden haber comprado. 

El gerente también necesita conocer cómo van las ventas, aunque no necesariamente necesita la misma información que utiliza el vendedor. 

 

### Lo que sabes del negocio 

El objetivo es llevar un mejor control de los clientes y de las ventas para que sea más fácil dar seguimiento a cada persona y saber cómo van los procesos. 

 

## PREGUNTAS 

### Contexto 

1. ¿Atiendes a varios clientes al mismo tiempo? 

Sí, depende del mes 

2. ¿Necesitas guardar los datos de contacto de tus clientes? 

Sí, es necesario para poder seguir con el proceso de venta 

3. ¿Necesitas registrar qué automóvil le interesa a cada cliente? 

Sí, ya que ayuda a tener más control en el proceso y por si el cliente llega a tener dudas sobre la compra de su vehículo. 

### Proceso actual 

4. ¿Realizas cotizaciones antes de una venta? 

Sí, es parte del proceso de venta y se hace antes de que se concrete la venta. 

5. ¿Programas pruebas de manejo con los clientes? 

Sí, ya que es una buena forma de convencer al cliente del carro 

6. ¿Das seguimiento al cliente después de la prueba de manejo? 

Sí, es importante saber sus opiniones, incluso eso ayuda en el futuro por si cambia de opinión respecto al modelo del auto 

7. ¿Manejas diferentes etapas durante el proceso de venta? 

Sí, se divide por pasos para que esté más organizado y dividir a los clientes respecto a su proceso de venta. 

### Dolores 

8. ¿Se te dificulta recordar en qué etapa está cada cliente? 

Sí, aunque esté anotado en algún lado, hay veces que se olvida actualizar el lugar 

9. ¿Has tenido problemas para encontrar información de un cliente? 

Sí, aunque se tenga en un excel medianamente organizado, hay muchos datos y a veces no se registran correctamente y se puede llegar a perder información. 

10. ¿Se te ha olvidado dar seguimiento a algún cliente? 

Sí, pasa que no es tan fácil mantener el orden de las etapas de venta de cada cliente, también es fácil perderle la pista al cliente y perder posibles ventas por esto. 

### Excepciones 

11. ¿Qué haces cuando un cliente deja de responder y después vuelve a contactarte? 

Se procura preguntar si todavía sigue interesado en el mismo modelo, si llega a cambiar de opinión a veces se tiene que repetir algunos pasos para que el cliente termine satisfecho. 

12. ¿Puedes cambiar la información del cliente si cambia de automóvil? 

Sí, actualmente se registra el modelo del coche pero fácilmente se puede cambiar. 

### Verificación de supuestos 

13. ¿Te sería útil tener en un solo lugar la información y el avance de cada cliente? 

Sí totalmente, porwque al tenerla toda en un lugar ordenado es más fácil tener todo más a la mano. 

 

## Supuestos confirmados 

<li>Confirmamos que el vendedor necesita guardar los datos de contacto de cada cliente. </li>

<li>Confirmamos que es importante registrar qué automóvil le interesa a cada cliente. </li>

<li>Se confirmó que el proceso de venta tiene diferentes etapas, como cotización, prueba de manejo, seguimiento y venta. </li>

<li>Confirmamos que dar seguimiento después de una prueba de manejo es importante para conocer la opinión del cliente. </li>

<li>También se confirmó que tener la información y el avance de cada cliente en un solo lugar sería útil. </li>


## Supuestos que resultaron diferentes 

<li>Pensábamos que atender varios clientes al mismo tiempo era algo constante, pero el vendedor comentó que depende del mes. </li>

<li>Pensábamos que el principal problema podía ser recordar la información de los clientes, pero también existe un problema importante con mantener actualizada la etapa en la que se encuentra cada uno. </li>


## Cosas que aparecieron y no esperábamos 

<li>El uso de Excel puede provocar que algunos datos no se registren correctamente o que sea difícil encontrar información entre tantos datos. </li>

<li>Si un cliente deja de responder y después regresa, puede ser necesario repetir algunos pasos del proceso. </li>

<li>Si un cliente cambia de automóvil, la información del modelo se puede modificar sin tener que crear nuevamente todo el proceso. </li>

<li>Perder el seguimiento de un cliente puede representar una posible pérdida de venta, por lo que no solo se busca organizar información, sino también evitar que se pierda el seguimiento. </li>
